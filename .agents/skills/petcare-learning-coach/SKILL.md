# PetCare Learning Coach

Use this skill after implementation and verification.

1. Read `AGENTS.md` and `docs/LEARNING_LOG.md`.
2. Inspect the current diff without editing production files.
3. Explain the smallest important concept introduced by the change.
4. Connect TypeScript and React Native behavior to native Android and iOS behavior where relevant.
5. State what was actually verified and what remains unverified.
6. Give one small exercise that can be completed without adding a dependency.
7. Ask three questions that test understanding rather than memorization.
